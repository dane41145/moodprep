# MoodPrep 中文说明

MoodPrep 是一个在本地运行的 Mac 应用，用来整理一整个文件夹的图片（老啤酒杯垫、酒标、徽记、包装等），为印刷或做 Midjourney 情绪板做准备。它不会上传你的图片；只有在你点击“重建”时，才会把那一张图发给你选择的 AI 模型。

## 它能做什么

- 扫描文件夹，找出完全相同和视觉相似的重复图片，推荐保留哪一张。
- 一套不依赖网络的本地工具：裁切（含 1:1 锁定）、扶正、画笔、填充、整图换色、去除背景色、加边框、重新配色、平整颜色噪点、放大。
- AI 重建（Gemini 或阿里云通义千问 Qwen）：去纹理、去透视、补全边缘、匀齐套印不准的圆环、修复拍摄的杯垫等预设，提示词可读可改。
- 每一步都是一个版本，可撤销、重做，按住“之前”可与上一版对比。替换原图后，原图保留在 `moodprep-originals` 文件夹里，随时可恢复。
- 界面和提示词都有简体中文：设置 → 语言。

## 安装（Apple Silicon 的 Mac，M1 及以后）

1. 在 GitHub 的 Releases 页面下载 `MoodPrep-<版本>-arm64.zip`，解压得到 `MoodPrep.app`。
2. 把 `MoodPrep.app` 拖进“应用程序”文件夹。
3. 这个应用没有 Apple 签名，第一次打开会被 macOS 拦下。二选一：
   - 在应用上按住 Control 点按 → 打开 → 再点“打开”；或
   - 在“终端”里执行一次：
     ```bash
     xattr -dr com.apple.quarantine /Applications/MoodPrep.app
     ```
4. 打开后，先到右上角设置里把语言切到“简体中文”。

Intel 的 Mac 目前没有现成的安装包，需要从源码构建（见文末）。

## 使用

1. 点“选择图像文件夹”，选一个只放图片的文件夹。第一次扫描会分析每张图（约 35 毫秒一张），以后再打开只需一秒左右。
2. 在图库里点一张图进入工作台。左边是预览，右边从上到下是：问题标签、质量评分、本地工具、AI 重建。
3. 本地工具每组有自己的“应用”按钮；画笔、填充、替换和 90° 旋转点一下就生效。
4. 满意后点右下角“替换原图”。原图会自动备份，提示条上的“撤销”可以立刻反悔。

## 建议

- **先用本地工具，再用 AI。** 裁切、填充、换色、加边框都是确定性的，不花钱也不会改动文字。AI 重建可能改动文字、比例和线条，接受前务必核对拼写。
- **AI 模型的选择：** 在中国大陆推荐用通义千问，设置里选 **中国（北京）** 地域，不需要翻墙；密钥在阿里云百炼（Model Studio）控制台申请，新密钥以 `sk-ws-` 开头，需要同时填写工作空间 ID。Gemini 需要能访问 Google 的网络。密钥由系统加密保存，不会写入图片文件夹。
- **杯垫和圆形标签**优先用“拍摄的杯垫”和“匀齐边框”两个预设；输出选 2K 或 4K 再放大。
- **不要在处理时手动改动那个文件夹**（改名、移动文件），否则程序会当成新图重新扫描。
- **备份**：`moodprep-originals` 里是所有被替换过的原图，`.moodprep` 是程序自己的缓存，都不要删；但整个文件夹随时可以拷贝到别处，程序会照常工作。
- **大图较慢：** 4000 万像素以上的照片，一次填充可能要几十秒；先裁切或缩小再处理会快得多。

## 从源码构建（可选）

需要 Node.js 20 及以上和 Xcode 命令行工具。在大陆下载 Electron 需要走镜像：

```bash
npm config set registry https://registry.npmmirror.com
export ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
git clone https://github.com/dane41145/moodprep.git
cd moodprep && npm install && npm run app
```

`npm run app` 会构建、安装到“应用程序”并打开它。
